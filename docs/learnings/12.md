# Aprendizajes del ticket 12: cartelera con filtros

| Aprendizaje                                                                                                                  | Destino                                              |
| ---------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| `/rdd` no se corre en este proyecto, salvo que el usuario lo pida explícitamente: de `/implement` se pasa directo a `/retro` | `AGENTS.md` (Flujo)                                  |
| Antes de escribir a mano un botón, input, select o chip, buscar el átomo en `src/shared/components/atoms/`                   | Skill `react-components` (checklist)                 |
| `outline-none` en un input solo si el contenedor muestra el foco con `has-focus-visible:`                                    | Skill `tailwind` (Foco visible)                      |
| Los parámetros de la URL usan los nombres del backend y una URL inválida se sanea                                            | Ya aplicado en el ADR 0002                           |
| Constantes y "enums": union pura, array `as const` o `as const satisfies Record`                                             | Ya aplicado en la skill `typescript-types-constants` |
| Partir el JSX largo en subcomponentes del mismo archivo                                                                      | Ya aplicado en `react-components` y `CLAUDE.md`      |
| Los tests de red verifican reglas, no los datos del seeder                                                                   | Ya aplicado en `CLAUDE.md` (Tests) y `workflow-ui`   |
| No commitear un test en rojo; los valores esperados salen de la fuente real                                                  | Ya aplicado en `implement` y `git-workflow`          |
| En `/retro`, buscar primero una skill del tema antes de elegir el destino                                                    | Ya aplicado en la skill `retro`                      |
